# v1.2.96

## 单节点 CVV 导入热修复

- 修复标准 Master 单节点部署未配置环境变量时，六列开号数据被错误拒绝为“未启用单节点临时 CVV 交付”的问题。
- Master 节点默认允许六列导入；可通过 `MAILBOX_TEMP_CVV_MODE=disabled` 明确关闭，也可通过 `single_node` 明确启用。
- 从节点仍然拒绝 CVV 导入和读取；无法保证请求固定进入同一 Master 进程的多节点部署应明确关闭。
- `XXXX` 无 2FA、`MM/YYYY` 有效期和三／四位 CVV 的解析规则保持不变。

## 数据安全

- CVV 仍只保存在当前 Master 进程的易失内存，不写入数据库、文件、Redis、日志或备份。
- 首次查看前不开始倒计时；首次查看后当前操作员可在 30 分钟内重新查看。
- 服务重启、回收、改派、审核通过、操作员停用或会话撤销会立即清除 CVV。

## 验证

- 邮箱服务和控制器测试通过，覆盖默认启用、显式关闭、从节点拒绝及非法配置。
- Go 全量测试和 `go vet` 通过。
- 发布包含五个平台服务端更新包、同版本 Windows 邮箱助手及 SHA-256 校验文件。
- 不连接或部署服务器。

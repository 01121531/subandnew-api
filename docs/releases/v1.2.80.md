# v1.2.80 邮箱导入示例与异常反馈

## 更新内容

- 后台退款、开号导入弹窗展示两条可复制的虚构文本示例，复制不覆盖导入草稿；临时 CVV 六列示例按功能开关和管理员权限显示。
- 网页操作端和 Windows 邮箱助手增加“反馈问题”：邮箱无法登录、验证码异常、信用卡不可用（仅开号）、其他，可附 0～5 张截图。
- 反馈成功后暂停当前任务，停止凭据读取及正常提交，清除未领取 CVV，并自动进入下一条可处理任务。
- 后台新增独立“异常反馈”标签，支持筛选、私有截图、回复并恢复原操作员任务，或回复并回收。获额外授权的管理员可同时替换密码、2FA 或卡片资料。
- 回收、改派、停用后禁止恢复旧反馈分配；原操作员仍可查看本人历史，后任不能读取前任反馈或截图。
- 使用事务及版本校验防止重复反馈、正常提交与改派冲突；提交响应丢失时只核对记录，不自动重放。反馈及正常审核的附件不可交叉使用。

## 使用与安全

服务端和 Windows 助手请同时更新。客户端 ZIP 须完整解压后运行 `MailboxAssistant.exe`；未做代码签名，下载后先核对 SHA-256。本次只发布，不连接或部署服务器。

反馈说明及截图不得包含密码、密钥、完整卡号或 CVV；截图需自行遮挡，应用不承诺自动识别敏感内容。反馈截图保留 365 天，未提交附件 24 小时清理，处理记录继续保留。修改本站资料不等于自动修改 Google 密码或信用卡本身，已复制信息无法撤回。

临时 CVV 仍仅限显式单节点、实际授权前的短时一次性交付，不进入数据库。反馈和更换资料会使旧交付失效，恢复任务不会恢复旧 CVV。不得长期保留含 CVV 的导入源文件。

详见 [邮箱管理文档](../MAILBOX-MANAGEMENT.zh-CN.md) 和 [Windows 助手说明](https://github.com/01121531/subandnew-api/blob/v1.2.80/desktop/mailbox-assistant/README.md)。

# v1.2.85

## 账号筛选值不再限制 50 个

- 账号管理的快捷包含、快捷排除和高级筛选取消筛选值数量上限；手工输入、多选及批量添加均不再限制 50 个值，也不截断尾部数据。
- 后端查询、筛选模板、AI 账号查询和共用组件的接口授权、账号数据门户同步支持。
- 保留大小写不敏感去重、空值处理、每个值最多 200 字符的校验，以及数值比较一个值、区间两个值的原有语义。
- 不改变分页大小、实例数量限制、权限、金额计算、导出行数及基础请求大小保护。

## 验证

- 覆盖 51、1,000 及 1,001 个筛选值，验证尾部值参与匹配、排除、汇总和筛选模板保存恢复。
- 前端筛选与导出条件快照测试；Edge 桌面、手机及明暗主题的千条批量输入检查。
- Go 全量测试及 go vet；前端测试、类型检查、Lint、格式检查、Knip 和生产构建。

提供五个平台服务端更新包、Windows 助手和 SHA-256 校验文件。Windows 助手仅同步发布版本号，业务行为不变。本次不连接或部署服务器。

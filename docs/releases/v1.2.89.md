# v1.2.89

## 邮箱兼容导入补充

- 支持 `|` 分隔的邮箱资料、退款资料末尾空字段、空辅助邮箱占位和空格分组的 2FA 密钥。
- 退款导入增加“忽略额外字段”选项，默认关闭。开启后只在既定位置明确识别邮箱、密码及有效 2FA 时忽略后续非空字段，不扫描或猜测任意字段中的密钥。
- 预览逐行提示被忽略的内容类型，不显示额外令牌、密码或密钥；提交沿用预览时的选项。
- 密钥中的非法标点不自动删除；缺失或无效 2FA、混杂的凭据分隔符仍阻止整批导入。
- 开号的卡号、有效期、CVV 校验保持严格，不启用忽略额外字段；密码保持原文，兼容转换不访问第三方网站。

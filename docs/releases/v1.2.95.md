# v1.2.95

## 邮箱导入与凭据可用性

- 邮箱导入支持使用 `XXXX` 明确表示未提供 2FA，服务端不会将占位符保存为伪造的 OTP 密钥。
- 管理端、操作员网页和 Windows 邮箱助手会将此类账号显示为“未提供”或“无 2FA”，不会生成错误验证码。
- 开号邮箱有效期兼容 `MM/YY` 与 `MM/YYYY`，四位年份会规范化为两位年份保存。
- 兼容示例：`邮箱----密码----XXXX----卡号----09/2031----CVV`。

## CVV 查看窗口

- CVV 在首次查看前不会因导入时间经过而失效，操作员可以在实际处理任务时再领取。
- 首次成功查看后开启 30 分钟窗口，当前操作员可在窗口内重新查看；到期后自动清除。
- 回收、改派、审核通过、操作员停用、会话撤销或服务重启会立即使未清除的 CVV 失效。
- CVV 仍仅保存在服务端进程易失内存中，不写入数据库、文件、日志、缓存或备份。

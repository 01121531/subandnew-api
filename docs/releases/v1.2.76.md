# v1.2.76 - 邮箱管理与独立操作员

## 更新内容

- 新增邮箱池、操作员、截图审核和操作记录，提供独立操作员登录入口及复制按钮。
- 支持 XLSX、CSV 和文本批量导入，先校验预览，最多 1,000 条；错误整批拒绝，重复邮箱不覆盖。
- 支持分配、回收、改派及退回重提；操作员只能处理本人的有效分配。
- 按需查看密码和服务端动态验证码，原始 2FA 密钥不回传；审核通过立即收回凭据读取权。
- 每次提交 1～5 张截图，使用私有鉴权存储并移除图片元数据；已提交图片保留 365 天，草稿保留 24 小时。
- 新增独立功能权限、会话隔离、操作审计、并发版本检查和过期附件清理。

## 升级注意

- 使用 HTTPS；配置持久化 `MAILBOX_ATTACHMENT_DIR`，多节点需共享私有图片目录。
- 数据库、图片目录和加密主密钥均需备份。不要把图片目录暴露为静态地址。
- 普通管理员须显式授予邮箱管理权限，操作员由管理员创建，无公开注册。
- 已经展示或复制的凭据无法追溯撤回；彻底撤销邮箱访问需要在 Google 侧轮换密码和 2FA 密钥。
- 模块不会自动登录 Google、读取邮件或使用第三方验证码网站。

详细说明见 [邮箱管理与独立操作员](../MAILBOX-MANAGEMENT.zh-CN.md)。

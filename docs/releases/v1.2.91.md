# v1.2.91

## 操作员网页粘贴截图

- 正常截图提交和问题反馈增加“粘贴截图”按钮，保留选择文件上传。
- 当前邮箱详情支持 Ctrl+V / Command+V，图片进入现有预览和私有草稿上传流程。
- 沿用最多 5 张、每张 10MB、PNG/JPEG/WebP 校验、权限核验、移除和失败重试。
- 剪贴板无图片或读取被拒绝时展示明确提示；纯文本粘贴不受影响，不读取 HTML 中的远程图片。
- 上传、提交及剪贴板读取期间防止重复操作；任务切换后丢弃旧的异步读取结果。
- 不改数据库、接口、审核流程或 Windows 助手行为。

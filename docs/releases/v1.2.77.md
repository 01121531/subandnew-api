# v1.2.77 - 操作员表单与路由预加载修复

## 修复内容

- 操作员用户名校验与服务端保持一致：3～96 位，以英文字母或数字开头，允许英文字母、数字及 `@ . _ + -`。中文姓名可以填写到显示名称。
- 非法用户名、超长显示名称和纯空白密码在提交前显示具体原因，并定位错误字段，避免无效请求引发 400。
- 保留密码原有空格；密码留空仍自动生成。重复用户名错误显示在用户名字段。
- 修正“操作员资料无效”被误提示为“已停用”的文案。
- 关闭自动悬浮路由预取，避免懒加载预取与快速页面切换竞争时出现 `_nonReactive` 异常；正常点击加载和权限校验保持不变。

## 验证

- 前端 191 项测试、类型检查、Lint、格式检查、未使用代码检查和生产构建通过。
- 操作员创建及列表 HTTP 回归测试通过，包括合法请求、错误请求、中文显示名称、密码自动生成及敏感字段裁剪。
- Edge 桌面、手机及明暗主题验证通过，使用虚构操作员和本地测试接口。

本次不修改数据库、凭据处理、邮箱分配或截图审核流程，不部署服务器。

# v1.2.83 邮箱可恢复删除与 CVV 导入说明

## 更新内容

- 邮箱池新增单条和批量“删除”，移入归档，可恢复。仅未分配或已回收邮箱允许归档，已分配邮箱须先回收。
- 新增“归档邮箱”视图，支持退款／开号分别搜索、分页及恢复。恢复后为未分配，不恢复旧任务或临时 CVV。
- 归档保留原邮箱 ID、加密资料、分配历史、截图审核和异常反馈；同类型重复导入提示“邮箱已归档，请先恢复”。截图仍沿用原有保留期限。
- 归档后停止密码、验证码和卡片读取，禁止补发临时 CVV，并清除尚未领取的 CVV。批量操作使用事务和版本校验，任何冲突整批拒绝。
- 开号导入始终展示五列及可选六列虚构示例。六列复制只在临时 CVV 可用且管理员有权限时开启，明确区分未开启、节点不支持、权限不足及状态读取失败。
- 退款三列和开号五列导入保持兼容，不自动修改部署配置。CVV 仍为单节点内存临时交付，10 分钟过期，领取一次后删除。

## 使用

升级服务端后，在“邮箱管理 → 邮箱池”选择邮箱，点击“删除”。需要找回时进入“归档邮箱”并恢复。功能沿用邮箱导入管理权限，操作员无归档管理入口。

本版本包含 Windows 助手与五个平台服务端更新包。助手保留 v1.2.82 的任务读取兼容修复；本次归档和示例功能需要服务端更新。

## 验证

- Go 全量测试、迁移测试、归档／恢复事务与并发分配测试、凭据在途收权、历史截图权限测试及 `go vet`。
- 前端测试、类型检查、Lint、格式检查、生产构建；Python/Qt 40 项测试、Ruff、Mypy。
- 本地 HTTPS 虚构数据在 Edge 320、390、768、1440px 明暗主题下验证归档、恢复、示例复制、导入预览及无横向溢出；验证 CVV 不可用原因和读取失败后重试。
- Windows 助手本地回归反馈、截图、自动下一条、管理员修正恢复及历史读取；发布附件与 SHA-256 校验。

仅推送和发布，不连接或部署生产服务器。未在独立无 Python 的干净虚拟机或全部实体多屏设备上验收。归档不永久擦除数据，不能撤回已经复制或下载的资料。

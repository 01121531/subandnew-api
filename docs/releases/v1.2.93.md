# v1.2.93

## 供货台账号异常与运行指标

- 账号状态增加健康状态、最近异常、异常类型、冷却原因及采集时剩余时间，桌面和手机端一致显示。
- 同时展示代理异常和冷却原因，避免只有“异常”而无法定位问题；上游未提供原因时明确提示，不伪造正常状态。
- 每个账号增加 RPM、TPM、并发、活跃会话及对应上限；真实零值保留，缺失数据展示 `--`。
- 管理员可分别控制四项账号指标，隐藏当前值时同步隐藏上限；状态未授权时不返回异常详情。沿用责任管理员权限约束、缓存与失败回退的响应裁剪。
- 幂等迁移沿用既有相关指标权限，不额外开放已隐藏的指标；旧管理客户端兼容。
- 异常摘要复用敏感信息脱敏，结构化异常不返回完整上游响应。不新增上游请求，不改变缓存周期或上传流程。

# v1.2.97

## 操作员网页 CVV 显示修复

- 修复操作员网页的开号任务只显示密码、2FA 和卡片，却没有渲染 CVV 查看入口的问题。
- 开号凭据区域新增独立“CVV 安全码”，操作员点击查看后才向服务端读取，可直接复制。
- 显示服务端交付窗口剩余时间；本地隐藏后仍可在服务端 30 分钟窗口内重新查看。
- CVV 未提供或已失效时只提示该字段不可用，不再错误锁住密码、2FA 和卡片等其他凭据。
- 退款任务不显示 CVV，普通账号 DTO 和前端缓存仍不包含 CVV。

## 验证

- 前端 301 项测试、类型检查、Lint、格式检查和生产构建通过。
- 覆盖开号 CVV 请求、权限复核、未提供状态、缓存隔离和退款任务隐藏。
- 发布包含五个平台服务端更新包、同版本 Windows 邮箱助手及 SHA-256 校验文件。
- 不连接或部署服务器。

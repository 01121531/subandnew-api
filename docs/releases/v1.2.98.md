# v1.2.98

## 更新内容

- 临时 CVV 可使用专用非持久化 Redis，应用升级或重启后仍可读取未过期数据。
- Redis 必须关闭 RDB 与 AOF；配置不安全时服务拒绝启用 CVV 导入。
- 操作员首次查看后开始 30 分钟有效期；管理员凭据权限可在有效期内重复查看，且不启动或延长操作员计时。
- 邮箱重新导入增加“更新已有邮箱”，更新密码、2FA、卡片和 CVV，同时保留操作员绑定、任务状态与历史。
- Docker Compose 默认增加独立的易失 CVV Redis。

## 部署配置

```env
MAILBOX_TEMP_CVV_MODE=redis
MAILBOX_TEMP_CVV_REDIS_CONN_STRING=redis://:password@mailbox-cvv-redis:6379
```

专用 Redis 必须以 `--save "" --appendonly no` 启动。旧版本进程内存中已丢失的 CVV 无法恢复，需要管理员重新补发或使用“更新已有邮箱”重新导入。

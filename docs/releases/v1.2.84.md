# v1.2.84

## 后台截图全屏查看

- 邮箱管理的截图审核和异常反馈支持点击整张缩略图或放大按钮，进入独立全屏查看器，不再受普通弹窗宽度限制。
- 默认完整适应屏幕，提供放大、缩小、适应屏幕、原始尺寸（100%）、缩放比例和关闭按钮。
- 支持鼠标滚轮缩放、拖动查看、手机双指缩放和单指拖动；工具栏保持可见。
- 关闭查看器保留审核弹窗、审核意见及滚动位置，Esc 只关闭当前图片，焦点返回原截图。再次打开重新适应屏幕。
- 图片复用已鉴权读取的原始 Blob，缩放不重复请求。图片加载失败、过期或查看期间失效时停止放大查看，保留安全提示。
- 适配手机、桌面及明暗主题；操作员网页、Windows 助手业务行为、接口和截图保留期限不变。Windows 助手仅同步发布版本号。

## 验证

- 前端单元测试、类型检查、Lint、格式检查、Knip 和生产构建。
- Edge 320、390、768、1440px 明暗主题，高清长图及横图，100% 尺寸、滚轮、拖动、双指缩放、键盘、焦点恢复和审核草稿保留。
- 图片过期、无效图片、请求失败及查看期间失效；确认缩放不增加图片请求。
- Go 全量测试、go vet，以及 Windows 助手 Python/Qt 回归和发布包自检。

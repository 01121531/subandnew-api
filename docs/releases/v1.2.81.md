# v1.2.81 邮箱助手空任务与刷新状态修复

## 修复内容

- 空任务时隐藏截图、反馈及提交区域，显示分配检查说明和明确的刷新入口，避免点击按钮无反应造成“卡住”的错觉。
- 网络失败、响应格式异常、任务状态不匹配与真正空队列分别展示，不再静默丢弃不可处理数据后显示没有任务。
- 刷新时清空旧任务和分页状态，防止失败后残留旧导航；上一条、下一条及截图操作按实际可用状态启用。
- 未粘贴截图时提交给出明确提示；恢复有任务后重新显示资料及操作区。

## 使用

下载新版 Windows 助手 ZIP，完整解压后运行 `MailboxAssistant.exe`。本次修复位于客户端，不改变服务端接口、任务分配、权限或凭据读取范围；异常反馈仍需要服务端 v1.2.80 或更新版本。

若提示没有可处理任务，请管理员核对当前操作员、退款/开号类型及任务状态。待审核、已通过和异常待处理不在待处理队列；分配或恢复后点击刷新。本次没有连接生产环境核查具体账号，不能凭截图确定后台是否已分配任务。

## 更新包与验证

- Windows x64 助手、对应源码 ZIP、五个平台服务端包及 SHA-256 校验文件。
- Python/Qt 回归测试、Ruff、Mypy，以及空队列、刷新失败、任务恢复、窗口尺寸与明暗主题检查。
- 正式包下载校验及隔离 Python 环境路径的运行时自检；未在独立无 Python 的干净虚拟机或全部实体多屏设备上验收。
- 仅推送和发布，不部署服务器。

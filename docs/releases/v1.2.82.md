# v1.2.82 邮箱助手任务读取兼容修复

## 修复内容

- 修复旧服务端不支持 `status=actionable` 时，网页可见待处理任务而助手返回空队列的问题。改为读取与网页一致的普通分配列表，由客户端保留待处理及已退回任务。
- 自动跳过仅包含待审核、已通过或异常待处理记录的分页，保持按邮箱 ID 顺序上下条，不提前读取其他邮箱凭据。
- 保留 v1.2.81 的空任务提示、刷新失败区分、无任务操作隐藏及截图提交提醒。
- 切换类型、会话或隐藏后丢弃旧分页响应；进入具体账号后仍检查当前分配，不能通过兼容查询扩大访问范围。

## 使用

下载 v1.2.82 Windows 助手 ZIP，完整解压后运行 `MailboxAssistant.exe`。本次任务读取兼容修复位于客户端，不修改后台分配、数据库或接口。完整异常反馈功能仍需服务端 v1.2.80 或更新版本。

已在本地虚构数据中复现旧查询返回空、新查询可加载已分配开号任务的差异；没有连接生产环境，不能据此断言具体线上版本或全部空任务原因。若仍为空，请核对登录站点、操作员及任务类型。

## 验证与发布

- Python/Qt 40 项测试、Ruff、Mypy；覆盖旧查询兼容、历史分页跳过、前后翻页、空队列、失败恢复及旧响应隔离。
- 本地 HTTPS 兼容场景：前 22 条为已通过记录，助手跨页找到 10 条待处理开号任务，上下条及凭据读取通过。
- Windows 助手 ZIP、源码包、五个平台服务端包及 SHA-256；正式包下载校验和隔离 Python 环境路径的运行时自检。
- 未在独立无 Python 的干净虚拟机或全部实体多屏设备上验收。仅推送和发布，不连接或部署服务器。

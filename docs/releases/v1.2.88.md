# v1.2.88

## 邮箱兼容导入

- Excel 和 CSV 支持在单个单元格中使用 `----` 或制表符分隔邮箱资料，继续兼容原有分列格式和文本导入。
- 退款资料支持“邮箱、密码、辅助邮箱、2FA”格式；辅助邮箱不保存，预览明确提示后由管理员确认导入。
- 支持从 HTTPS 链接的 `#` 片段中本地提取有效 Base32 密钥，不访问第三方网站，不保存原始链接。
- 预览按行显示兼容转换提示与错误原因，不回显密码、密钥或其他额外凭据。
- 不明确的额外字段、无效 2FA、重复邮箱仍阻止整批导入；不会跳过错误行或猜测缺失资料。
- 密码首尾空白、开号卡号文本校验、临时 CVV 权限及整批原子性保持不变。

## 验证

- Go 导入回归及全量测试、go vet。
- 前端测试、类型检查、Lint、格式检查及生产构建。
- 使用虚构数据检查导入预览与移动端提示，不向测试系统导入真实凭据。

仅发布更新包，不部署服务器。此版本不改变 Windows 助手的操作流程。

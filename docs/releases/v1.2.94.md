# v1.2.94

## 邮箱提交备注

- 退款、开号任务增加提交备注，网页操作端和 Windows 邮箱助手同步支持。
- 可仅填写备注、仅上传截图，或两者一起提交；全部留空时不允许提交。
- 备注支持换行，最多 2,000 个字符；管理员审核、操作员工作详情和本人提交记录可查看完整备注。
- 保留原审核流程、权限隔离、版本冲突检查及敏感资料提示，退回重提不会覆盖旧记录。
- 已有截图提交兼容，旧提交备注为空；备注不进入审计正文或本地持久化草稿。

本次仅发布邮箱备注相关改动，定时账号导出与邮件附件任务已暂停，不包含在本版。

## 验证

- Go 全量测试及 `go vet` 通过，覆盖旧数据迁移、两类邮箱、并发提交和权限隔离。
- 299 项前端测试，以及类型检查、Lint、格式检查、Knip 和生产构建通过。
- Windows 助手 63 项测试及 32 项子测试通过，Ruff、格式检查和 Mypy 通过。
- Edge 在 320、390、768、1440px 的明暗主题下验证退款和开号提交，共 16 组流程通过。

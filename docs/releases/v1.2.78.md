# v1.2.78

## 更新内容

- 邮箱管理分为独立的退款邮箱池和开号邮箱池，同一邮箱可分别导入，分配、截图及审核历史互不混用。
- 退款保持邮箱、密码、2FA 三列导入；开号新增卡号与有效期，支持文本、CSV 和 XLSX 五列导入。
- 卡号及有效期独立加密；预览和列表仅展示卡号后四位，完整卡片资料按需读取并重新校验权限。
- 不导入、不存储 CVV；额外导入列、数值型 Excel 卡号、无效卡号及过期有效期均拒绝导入。
- 操作员共用登录入口，分别处理两类分配；通过审核、回收、改派或停用后停止后续凭据访问。
- 管理端与操作员页面增加类型切换、分类型历史查询及截图脱敏提示，切换时清理敏感详情和导入草稿。
- 修复操作员退出后会话状态未同步到页面的问题；密码和卡片详情自动隐藏，失效会话清除私有缓存。

## 升级说明

- 已有邮箱自动归入退款，保留原记录 ID、加密凭据、分配和截图历史；迁移可重复执行。
- 旧请求未传类型时继续按退款处理；两池记录创建后不能互相转换。
- 升级前请备份数据库、私有截图目录和加密密钥。卡片密文同样进入数据库备份，需要限制访问并管理备份保留周期。
- 加密存储不等于 PCI DSS 合规认证。实际支付时在支付服务安全页面填写 CVV，上传截图须遮挡 CVV 和完整卡号。
- 详细说明见 [邮箱管理文档](../MAILBOX-MANAGEMENT.zh-CN.md)。

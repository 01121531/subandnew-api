# v1.2.90

## 邮箱分批成功导入与失败清单

- 退款、开号导入预览分别显示可导入和失败数量，确认后跳过错误行，其他有效邮箱继续导入。
- 导入完成保留结果，展示实际成功及未导入数量；预览与结果页均可下载失败 CSV。
- 失败清单包含原始行号、可识别的邮箱及失败原因，不包含密码、2FA 密钥、完整卡号或 CVV。
- 重复、已存在、已归档及提交期间冲突的邮箱不覆盖旧资料；重复提交不会重复创建。
- 旧客户端未传 `allow_partial` 仍保持原有整批校验行为；文件安全检查、权限及存储故障仍阻止请求并回滚事务。
- 兼容 Excel、CSV、文本及显式忽略额外字段；不修改 Windows 助手操作流程或数据库结构。

## 验证

- Go 全量测试、go vet，覆盖部分成功、全部失败、重复冲突、归档及事务回滚。
- 前端测试、类型检查、Lint、格式检查、生产构建。
- Edge 320、390、768、1440px 明暗主题：虚构资料真实预览、部分导入、失败清单下载及重复提交保护。

# v1.2.79 邮箱悬浮助手

## 更新内容

- 新增 Windows 10/11 x64 Python + PySide6 免安装邮箱助手，独立操作员登录、退款/开号队列、置顶、折叠、托盘及跨页上下条。
- 邮箱、密码、动态验证码、卡号、有效期及可领取的临时 CVV 均可点击数值复制。复制前重新校验分配，保留原文和前导零；过期验证码先刷新。
- 支持应用内粘贴、预览、移除截图，最多五张；提交后自动下一条。失败保留已上传附件，结果不确定时核对历史，不自动重放。
- 当前 Windows 用户 DPAPI 保护记住的会话，不保存登录密码。HTTPS 严格校验证书，不自动跨站跳转；换任务、隐藏、锁屏及注销清理敏感字段。
- 服务端增加兼容的 `status=actionable` 队列筛选，合并待处理及已退回后按 ID 倒序分页。
- 开号五列导入继续兼容；显式单节点部署可选第六列临时 CVV，预览脱敏、10 分钟内存保留、一次性领取及受权限保护的补发入口。

## 使用与安全

下载客户端 ZIP 后完整解压，运行 `MailboxAssistant.exe`，填写本站 HTTPS 地址和独立操作员账号。服务端需先升级到本版本；本次不执行部署。应用未签名，Windows 可能提示 SmartScreen，请先核对 SHA-256。

临时 CVV 默认关闭。只在已确认单节点时配置 `MAILBOX_TEMP_CVV_MODE=single_node`；多节点禁止启用。CVV 不进入数据库或持久缓存，进程重启丢失，客户端复制后立即隐藏。仅限实际授权前短时交付，不得用于授权后留存或重复交易，含 CVV 的导入源文件不能长期保存或备份。截图必须遮挡完整卡号及 CVV，剪贴板历史与已复制信息无法追溯撤回。

详见 [客户端说明](https://github.com/01121531/subandnew-api/blob/v1.2.79/desktop/mailbox-assistant/README.md) 和 [邮箱管理文档](../MAILBOX-MANAGEMENT.zh-CN.md)。加密、限时及单次领取不构成支付数据合规认证。

## 验证

- Go 全量测试、`go vet`、可达漏洞检查；前端测试、类型检查、Lint、格式检查、未使用代码检查及生产构建。
- Python 单元/Qt 测试、Ruff、Mypy，覆盖六类复制、旧响应丢弃、OTP 到期、剪贴板占用、任务收权和不确定提交。
- 本地 HTTPS 虚构数据完成登录、复制、截图提交、自动下一条和只读历史；不使用真实邮箱或支付资料。
- Qt 320/400/720px、100%/150%/200% 缩放、长文本和明暗主题；Edge 320/390/768/1440px 六列导入、脱敏预览和临时补发。
- 打包 EXE 在清空 Python 环境路径后通过运行时自检，包含 Qt 界面、TLS、PNG/JPEG/WebP 及 DPAPI；构建隔离外部 DLL 搜索路径并统一 VC 运行库。
- 包含 Windows 锁屏通知回调和置顶切换检查；尚未在独立、未安装 Python 的干净虚拟机及不同实体多屏设备上验收，不将运行时隔离自检等同于这些测试。

# v1.2.87

## 更新内容
- 邮箱管理的操作员列表新增已提交邮箱、退款已提交、开号已提交、待处理异常和累计异常统计。
- 默认累计全部，支持北京时间今天、近 7 天、近 30 天和自定义日期。按操作员与邮箱记录去重，退回重提不重复计算邮箱数，另保留实际提交次数。
- 点击统计查看对应邮箱列表，继续点击邮箱可查看该操作员的分配历史、提交截图、审核结果与异常反馈。
- 当前任务独立汇总待处理、待审核、已通过、已退回及待处理异常，不随历史日期筛选变化。
- 详情复用原有截图放大、审核和异常处理入口；返回保留筛选、分页及滚动位置。
- 历史业绩不因回收、改派、停用或归档消失；详情不包含其他操作员记录，不自动读取敏感凭据。
- 统计与详情需要操作员管理、邮箱查看和审核权限；原有操作员管理行为保持兼容。

# 操作员工作统计

入口：邮箱管理 → 操作员。管理员需同时具备操作员管理、邮箱查看和审核权限才能使用统计与工作详情；只有操作员管理权限时，原有创建、编辑、密码重置和注销会话仍可使用。

## 统计口径

- 已提交邮箱：所选时间内至少提交一次截图的邮箱，按操作员和邮箱记录 ID 去重。重提不会重复计算邮箱，提交次数单独计算。
- 退款已提交、开号已提交：上项的类型拆分。同地址在两个池中是独立记录。
- 累计异常：所选时间内反馈过问题的去重邮箱，包含已解决或分配已失效的反馈。
- 当前任务：当前仍有效的分配，按状态汇总，与历史时间筛选无关。待处理异常还要求操作员启用且存在未解决反馈。
- 历史记录：回收、改派、归档或停用不删除原操作员的提交与反馈。多个操作员曾处理同一邮箱，各自统计自己的行为。

默认累计全部；今天、近 7 天和近 30 天包含北京时间今天。自定义开始日及结束日均包含，服务端转换为北京时间开始日零点到结束日下一天零点的左闭右开区间。

## 查看详情

点击数字进入对应分类，点击邮箱查看该操作员的完整处理历史。邮箱列表的提交次数、最近提交及反馈时间为该操作员对此邮箱的累计数据；日期筛选只限定哪些邮箱进入列表。详情历史不受统计日期限制，并按分配、提交和异常反馈分别分页。

截图通过原有鉴权接口读取，保留到期清理与全屏查看能力。审核和反馈处理使用原有权限与版本校验。统计响应、详情响应均不含密码、密钥、完整卡号或 CVV，也不自动访问凭据接口。

## 接口兼容

- `GET /api/mailbox-management/operators` 默认不返回统计；添加 `include_stats=true` 后返回当前页操作员的 `work_summary`。
- `GET /api/mailbox-management/operators/:id/work-summary` 返回操作员、汇总和解析后的北京时间区间。
- `GET /api/mailbox-management/operators/:id/work-accounts` 返回筛选后去重邮箱分页。
- `GET /api/mailbox-management/operators/:id/work-accounts/:account_id/history` 返回该操作员的分配、提交与反馈分页，必须明确指定退款或开号类型。

统计读取已有本地历史，不建立上游采集任务，不增加统计持久化表。历史截图继续遵守原有保留期限。

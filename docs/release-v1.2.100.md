# v1.2.100

## 操作员网页卡片直显
- 退款邮箱卡片直接展示邮箱、密码和动态验证码；开号卡片额外展示完整卡号、有效期和可用 CVV，无需逐项点击显示。
- 点击数值或独立复制按钮即可复制，卡号与有效期分别复制，密码原文及验证码、CVV 前导零保持不变。
- 卡片进入屏幕后才读取资料，最多同时执行 4 个读取流程；列表与详情共享当前可见账号的内存资料，避免重复读取 CVV。
- 可见卡片不再 60 秒自动隐藏。验证码按服务端有效期刷新，CVV 仍遵守现有服务端有效期，不延长或重置。
- 离屏、翻页、切换类型、退出和页面转入后台时清理敏感资料；定期及复制前重新检查分配和权限，断网或权限失效不能继续复制旧资料。
- 单字段错误独立提示并支持重试，未配置 2FA 和不可用 CVV 显示明确状态。

## 验证与更新
- 前端自动化测试、类型检查、Lint、格式检查和生产构建通过。
- Edge 使用虚构数据检查 320、390、768、1440px 明暗主题，覆盖六类复制、滚动清理、详情共享、超过 60 秒展示及后台和断网清理。
- 仅调整操作员网页；管理员页面和 Windows 助手功能不变。
- 优先提供 Linux amd64、arm64 更新包及 checksums-linux.txt，其他附件由发布流水线生成。不部署服务器。

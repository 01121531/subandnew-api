# 实例排序与管理员授权

## 实例排序

超级管理员在「实例管理 → 实例排序」中拖动实例，或使用上下移动按钮，然后保存。排序是全站统一配置，不改变默认实例。新增实例排在末尾；供货商门户按照对应实例的顺序显示线路，仍只显示对外别名。

若其他管理员同时修改了排序，保存会提示版本冲突。当前草稿会保留，重新读取最新顺序后再调整。

## 创建管理员

超级管理员在「用户管理 → 创建管理员」中设置本站登录账号，并分别配置：

- 功能权限：允许使用哪些业务功能。
- 实例范围：指定实例，或全部实例。全部实例包含今后新增实例；指定范围为空表示没有实例权限。
- 数据可见性：金额、请求、Token、RPM、并发、账号数量、比例、邮箱、供应商、分组、状态和时间。

新管理员默认不开放业务功能、实例和数据字段，可以登录账户基础页面。必须同时具有功能权限和实例范围，才能访问对应业务数据。字段权限不能代替功能权限，也不能扩大实例范围。

一个管理员只有一套数据字段配置，应用于其所有授权实例。供应商邮箱同时需要「供应商信息」和「邮箱」权限；平均值、单次请求费用等派生指标需要对应输入指标的权限。

有创建实例权限的管理员会自动获得自己新建实例的范围，但不会因此增加功能或字段权限。实例连接信息继续遵守原有超级管理员限制。

## 权限变更

保存授权变更后，旧登录会话和实时连接失效，管理员需要重新登录。后台在响应时重新检查权限，缓存不会成为绕过限制的入口。

隐藏字段不能用于筛选或排序，也不会进入账号汇总、趋势、AI 查询或导出。账号数量隐藏时不返回精确总数及总页数，列表使用上一页、下一页；用户仍可能通过遍历已授权账号自行统计数量。

导出任务在创建、执行和下载时分别检查权限。收回字段或实例范围后，包含已隐藏数据的旧导出文件不能再下载；已经下载到用户本地的文件无法追溯撤回。

## 对外资源

接口授权和供货商资源记录责任管理员。实际可见范围为资源配置与责任管理员当前权限的交集。责任人被停用、删除或失去对应管理权限后，对外授权停止。超级管理员可以通过明确的接管操作恢复管理责任，操作记录进入审计。

普通管理员不能更换责任人或编辑其他管理员的资源以扩大权限。供货商全站默认权限、门户标题和上传方式设置仍由超级管理员维护。

## 升级兼容

旧管理员保留原功能权限，迁移为全部实例范围和原有字段可见性；旧对外资源补齐责任主体。迁移可重复执行，不覆盖后续人工配置。

旧客户端未提交新增数据授权配置时，不会清空已有配置。管理员授权与排序保存均有版本校验，不能使用过期草稿覆盖较新的配置。

本次不连接或部署目标服务器，账号快照和实时采集周期保持原样。

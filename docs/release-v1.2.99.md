# v1.2.99

## 更新内容
- 后台「邮箱管理 → 开号邮箱」新增「导出已完成账号」，一键导出全部待审核及已通过账号，不受分页、勾选和筛选影响。
- Excel 包含邮箱、密码、2FA 密钥、操作员、处理状态、最新提交备注、提交时间、审核时间和审核说明。未配置 2FA 输出 XXXX，非标准参数另附算法、位数和周期。
- 时间统一为北京时间；保留密码原文、备注换行，用户资料均按文本写入。
- 只导出当前有效分配的最新提交，排除回收、归档、异常及退回任务；不包含支付卡、CVV、动态验证码或截图。
- 同时校验邮箱查看、审核和凭据访问权限。导出期间资料或分配变化时拒绝返回旧文件；最多 10,000 条，超限不截断。
- 文件仅用于本次下载，不加入长期导出记录。下载文件含登录资料，请妥善保管。

优先发布 Linux amd64、Linux arm64 更新包与 checksums-linux.txt；其他平台附件由现有发布流水线生成。本次不部署服务器。

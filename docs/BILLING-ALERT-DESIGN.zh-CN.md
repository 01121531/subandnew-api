# 账单预警功能设计方案

## 1. 文档目标

本文档描述 SubAndNew API 控制平面的账单预警功能设计。系统根据保存的使用记录筛选条件，按实例独立统计指定账期内的美元消费，并根据折扣和美元兑人民币汇率计算人民币结算账单。当美元消费或人民币账单达到配置的预警档位时，系统通过邮件发送提醒。

本功能包含筛选模板、实例绑定、账期计算、汇率管理、多档预警、邮件通知、异常监控、预警记录与导出。

## 2. 已确认需求

- 支持自然日、自然周、自然月、自定义固定起止时间、每月指定日期开始和每 N 天循环等统计周期。
- 默认时区为 `Asia/Shanghai`，规则可以单独覆盖时区。
- 美元消费和人民币账单均可作为预警阈值。
- 每个预警档位可以独立选择美元或人民币。
- 人民币账单计算公式为：

  ```text
  人民币账单 = 美元消耗 × 折扣比例 × USD/CNY 汇率
  ```

- 直接复用使用记录页面的全部筛选条件，并支持保存为共享筛选模板。
- 一个筛选模板可以绑定多个实例，但每个实例独立计算、独立预警，不合并消费金额。
- 规则通过弹窗创建和编辑。
- 支持多个预警档位，以及每账期一次、按间隔重复和按金额增量重复等提醒策略。
- 一条规则允许配置多个收件邮箱。
- SMTP 由控制台统一配置，并支持发送测试邮件。
- 汇率支持全局默认策略和单条规则覆盖。
- 汇率支持自动更新、手工固定和一键刷新，公开数据源不得要求 API Key。
- 汇率计算支持记录日期汇率、当前最新汇率和账期固定汇率三种模式。
- 某实例连续统计失败默认达到 3 次时发送监控异常邮件，恢复后发送监控恢复邮件。
- 统计失败时保留最后一次成功数据，但不基于旧数据触发新的金额预警。
- 修改共享筛选模板后展示影响预览；确认生效后重置当前账期的预警发送状态。
- 只有超级管理员可以创建、修改和删除规则以及管理 SMTP；普通管理员只能查看有权限实例的规则状态和预警记录。
- 提供独立预警记录页面，并支持筛选和后台导出。

## 3. 信息架构

侧边栏新增以下菜单：

- `账单预警`：管理筛选模板、预警规则、实例绑定及运行状态。
- `预警记录`：查询金额预警、监控异常、监控恢复及邮件发送结果。

系统设置新增以下区域：

- `汇率设置`：管理全局汇率策略、自动更新计划、当前汇率和历史汇率。
- `邮件设置`：管理 SMTP、发件人信息和测试邮件。

新建预警规则使用居中弹窗或宽抽屉，按照以下步骤组织：

1. 基本信息。
2. 筛选模板与实例绑定。
3. 账期和时区。
4. 折扣与汇率策略。
5. 多档预警阈值。
6. 执行计划。
7. 收件人和邮件策略。
8. 影响预览与确认。

## 4. 筛选模板

### 4.1 模板范围

筛选模板复用使用记录页面的现有筛选能力，包括但不限于：

- 用户、账号、API Key、模型、渠道和分组。
- 请求类型、日志类型、计费类型和计费模式。
- 请求 ID、上游请求 ID、代理 ID 和上游模型校验。
- New API 与 Sub2API 各自支持的其他筛选字段。

模板继续支持动态选项、手工输入和多选值。

### 4.2 跨实例行为

一个模板可以绑定多个实例，但后台为每个实例创建独立的计算上下文和预警状态。如果模板中的模型、账号或分组在某个实例中不存在，该实例按零消费处理，同时在规则状态中显示“筛选项未匹配”。

### 4.3 版本管理

筛选模板采用版本化保存。修改模板时先展示以下影响：

- 绑定的实例和预警规则数量。
- 修改前后的筛选字段差异。
- 当前账期已经发送的预警档位。
- 预警状态重置的范围。

确认后生成新版本，所有绑定规则使用新版本，并重置当前账期的档位发送状态。历史预警记录继续保留原模板版本和筛选快照。

## 5. 账期设计

每条预警规则支持以下账期类型：

- 自然日。
- 自然周。
- 自然月。
- 每月指定日期和时间开始的循环账期。
- 自定义固定开始时间和结束时间。
- 每 N 天循环一次。

系统为每个“规则、实例、账期”生成独立账期快照，保存：

- 账期开始和结束时间。
- 时区。
- 筛选模板及版本。
- 折扣比例。
- 汇率模式和汇率快照。
- 各预警档位的发送状态。
- 最后一次成功统计结果。

所有账期边界在规则时区内计算，存储时统一转换为 UTC 时间戳。

## 6. 金额计算

### 6.1 美元消费

美元消费直接使用目标实例使用记录接口返回的实际消费字段。筛选条件、账期时间范围和时区必须完整传递给目标实例，确保列表、汇总、预警和导出的统计口径一致。

### 6.2 人民币账单

人民币结算金额采用以下公式：

```text
CNY = USD × discount_rate × USD_CNY_rate
```

计算时使用高精度十进制类型，数据库不使用浮点数保存金额和汇率。建议美元、人民币和汇率内部至少保留 8 位小数，页面根据业务需要格式化显示。

### 6.3 汇率模式

每条规则支持以下模式：

- `record_date`：先按日期聚合美元消费，再分别乘以每个日期的有效汇率后求和。
- `latest`：每次统计都使用规则当前最新汇率重新换算整个账期的美元消费。
- `cycle_fixed`：账期开始时保存一个汇率快照，整个账期固定使用该值。
- `manual`：使用规则填写的固定汇率，不被自动更新覆盖。

记录日期没有汇率时，向前查找最近一个有效工作日的汇率，并在计算快照中标记为历史回退值。

## 7. 汇率服务

### 7.1 数据源

主要数据源建议使用欧洲央行 ECB Data API。该服务无需 API Key，提供每日官方参考汇率和历史日期查询：

- [ECB Data API](https://data.ecb.europa.eu/help/api/data)
- [ECB 汇率数据](https://data.ecb.europa.eu/key-figures/ecb-interest-rates-and-exchange-rates/exchange-rates)

ECB 汇率以 EUR 为基础，可按以下方式计算 USD/CNY：

```text
USD/CNY = EUR/CNY ÷ EUR/USD
```

备用数据源建议使用无需密钥的 Frankfurter 公共 API：

- [Frankfurter](https://github.com/lineofflight/frankfurter)

页面统一使用“最新参考汇率”文案，不将工作日参考汇率描述为分钟级交易行情。

### 7.2 更新策略

- 支持后台每天自动更新。
- 支持超级管理员一键刷新。
- 支持规则使用全局默认策略或单独覆盖。
- 周末和节假日沿用最近一个有效工作日汇率。
- 主数据源失败时尝试备用数据源。
- 所有数据源均失败时保留最后一次有效汇率，并显示数据延迟。
- 汇率记录保存来源、观测日期、抓取时间、币种、数值和回退状态。

## 8. 预警档位

一条规则可以配置多个档位。每个档位包含：

- 档位名称和严重程度。
- 阈值币种：`USD` 或 `CNY`。
- 阈值金额。
- 提醒方式。
- 重复间隔或金额增量。
- 邮件主题模板。

支持以下提醒方式：

- `once_per_cycle`：每个账期达到阈值后只提醒一次。
- `repeat_interval`：达到阈值后按指定时间间隔重复提醒。
- `repeat_increment`：达到阈值后，金额每增加指定值再次提醒。

预警状态使用“规则、实例、账期、档位”为唯一维度保存。后台在事务中完成阈值判断和事件创建，并使用幂等键避免并发计算、任务重试或服务重启导致重复邮件。

## 9. 调度与计算流程

### 9.1 执行计划

每条规则支持：

- 指定分钟间隔。
- 预设的 5 分钟、15 分钟、30 分钟和 1 小时。
- 每天一个固定时间。
- 每天多个固定时间。

### 9.2 后台流程

1. 调度器查找到期规则。
2. 为每个绑定实例建立独立任务。
3. 获取数据库任务锁或租约，避免多节点重复执行。
4. 解析当前账期和筛选模板版本。
5. 请求目标实例的使用记录汇总。
6. 计算美元消费和人民币账单。
7. 保存本次成功统计快照。
8. 逐档判断阈值和重复提醒条件。
9. 在事务中创建预警事件和邮件投递任务。
10. 邮件工作器异步发送并记录结果。

## 10. 数据失败与监控异常

某实例统计失败时：

- 保留最后一次成功的金额和数据时间。
- 不使用旧金额触发新的账单阈值预警。
- 增加连续失败次数并记录错误原因。
- 页面显示“数据延迟”和最后成功时间。

连续失败默认达到 3 次时创建一次“账单监控异常”事件并发送邮件。异常期间继续记录失败，但不重复发送相同异常邮件。后续统计恢复成功时，清除失败计数并发送一次“账单监控已恢复”邮件。

## 11. SMTP 与邮件队列

### 11.1 SMTP 配置

超级管理员统一配置：

- SMTP 主机和端口。
- TLS、STARTTLS 或 SSL 模式。
- 用户名和密码。
- 发件人名称和发件邮箱。
- 回复地址。

SMTP 密码使用控制平面现有的加密服务保存，接口永不返回明文。系统提供“发送测试邮件”操作，并显示连接、认证和发送阶段的具体错误。

### 11.2 邮件内容

账单预警邮件至少包含：

- 实例名称和系统类型。
- 规则名称和筛选条件摘要。
- 账期和时区。
- 触发档位及币种。
- 当前美元消费。
- 折扣比例。
- 汇率、来源和观测日期。
- 当前人民币账单。
- 数据统计时间。
- 控制台预警详情链接。

邮件发送采用独立队列。失败时执行有限次数指数退避，不阻塞账单计算，也不重复创建预警事件。

## 12. 数据模型

建议新增以下数据表：

| 表名 | 用途 |
| --- | --- |
| `billing_filter_templates` | 筛选模板基本信息 |
| `billing_filter_template_versions` | 筛选条件版本和只读快照 |
| `billing_alert_rules` | 账期、折扣、汇率、计划和邮件配置 |
| `billing_alert_rule_instances` | 规则和实例绑定关系 |
| `billing_alert_thresholds` | 多档阈值和重复提醒策略 |
| `billing_cycle_snapshots` | 每个规则实例的账期固定参数 |
| `billing_evaluation_snapshots` | 每次成功统计的金额与数据状态 |
| `billing_alert_events` | 金额预警、监控异常和恢复事件 |
| `billing_email_deliveries` | 邮件收件人、发送状态和错误 |
| `exchange_rates` | 汇率历史、来源和观测日期 |
| `exchange_rate_settings` | 全局自动更新与默认策略 |
| `smtp_settings` | 加密 SMTP 配置 |

金额、比例和汇率字段应使用数据库定点十进制类型或统一的高精度字符串表示。筛选条件、计划配置和邮件策略使用结构化 JSON，并在写入时进行 Schema 校验。

## 14. 预警记录页面

预警记录页面展示：

- 事件类型：金额预警、监控异常、监控恢复。
- 实例、规则、筛选模板和账期。
- 触发档位和阈值。
- 美元金额、人民币金额、折扣和汇率。
- 汇率来源和观测日期。
- 数据统计时间。
- 收件人。
- 邮件发送状态、重试次数和错误原因。
- 创建时间和发送时间。

支持按时间、实例、规则、事件类型、币种、档位、邮件状态和收件人筛选。详情使用只读弹窗展示完整计算快照和邮件投递记录。

## 15. 权限与审计

超级管理员可以：

- 创建、修改和删除筛选模板及预警规则。
- 管理实例绑定、阈值、汇率和 SMTP。
- 手动执行计算和测试邮件。
- 查看全部预警记录。

普通管理员只能查看自己有权访问实例的规则运行状态和预警记录，不能读取 SMTP 凭据或修改计费规则。

以下操作必须写入审计日志：

- 创建、修改和删除模板或规则。
- 重置当前账期预警状态。
- 修改汇率策略或手动汇率。
- 一键刷新汇率。
- 修改 SMTP 和发送测试邮件。
- 手动执行规则。
- 导出预警记录。

## 16. 安全与可靠性

- SMTP 密码和其他敏感配置加密存储。
- 浏览器不直接请求汇率服务和目标实例，全部由控制平面代理。
- 目标实例请求继续使用现有 SSRF 防护、允许列表和凭据隔离。
- 汇率响应必须验证币种、日期、数值范围和 HTTPS 来源。
- 所有金额计算使用高精度十进制，禁止使用二进制浮点累计账单。
- 调度任务使用数据库锁、幂等键和唯一约束防重复。
- 邮件队列与统计任务解耦，邮件服务故障不会阻断后续账单统计。
- 服务重启后未执行任务继续调度，未发送邮件继续按队列重试。

## 17. 测试计划

### 17.1 金额与账期

- 验证全部账期类型和跨时区边界。
- 验证美元金额、折扣和人民币换算精度。
- 验证记录日期、当前最新、账期固定和手工汇率模式。
- 验证周末、节假日及缺失历史汇率回退。

### 17.2 筛选与实例

- 验证 New API 和 Sub2API 的全部筛选字段。
- 验证多选、空筛选和未知字段。
- 验证一个模板绑定多个实例时分别计算和预警。
- 验证筛选项不存在时按零消费处理。
- 验证模板修改预览、版本保存和当前账期状态重置。

### 17.3 阈值与通知

- 验证美元和人民币混合档位。
- 验证每账期一次、按时间重复和按金额增量重复。
- 验证并发执行、任务重试和服务重启不会重复发送。
- 验证多收件人、测试邮件和 SMTP 失败重试。

### 17.4 异常与恢复

- 验证统计失败时保留最后成功数据但不触发金额预警。
- 验证连续 3 次失败只发送一次异常邮件。
- 验证恢复后只发送一次恢复邮件。
- 验证汇率源失败、备用源切换和陈旧汇率提示。

### 17.5 权限与 UI

- 验证超级管理员和普通管理员的数据范围。
- 验证敏感配置不通过 API 返回。
- 验证浅色、暗色以及 375px、768px、1440px 布局。
- 验证弹窗键盘操作、焦点恢复和长文本不溢出。
- 验证预警记录筛选和后台导出。

## 18. 实施顺序

1. 建立数据表、账期计算和高精度金额模块。
2. 实现汇率服务、历史汇率和自动更新任务。
3. 实现筛选模板、版本管理及实例绑定。
4. 实现规则预览、金额计算和账期快照。
5. 实现多档阈值、调度器、幂等事件和异常恢复状态机。
6. 实现 SMTP、测试邮件和异步邮件队列。
7. 实现账单预警、汇率设置、邮件设置和预警记录页面。
8. 接入后台 CSV 导出、RBAC 和审计日志。
9. 完成自动化测试、生产构建和响应式检查。

## 19. 验收标准

- 相同筛选条件下，预警统计金额与使用记录页面汇总一致。
- 人民币金额能够追溯到美元金额、折扣、汇率模式和具体汇率记录。
- 多实例绑定始终按实例独立计算和触发。
- 同一账期同一档位不会产生非预期重复邮件。
- 数据失败、恢复和汇率陈旧均有清晰状态和通知。
- 历史预警记录不因模板、折扣或汇率策略后续修改而变化。
- 超级管理员和普通管理员权限符合设计要求。
- 后台任务在服务重启后可以安全恢复。

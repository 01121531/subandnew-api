# Claude Gateway 供货商管理

## 开通

1. 超级管理员进入“供货商”，创建本站供货商账号和独立密码。普通管理员需要另行授予 `supplier_management` 的查看、管理、审计权限。
2. 新供货商继承“默认权限”；初始默认仅开放账号池和用量统计。管理员可以统一设置默认权限，或在供货商、实例绑定中逐项覆盖。
3. 为供货商绑定已创建的 Claude Gateway 实例，输入该实例上的供货商登录账号和密码。保存时通过上游登录及 `/api/auth/me` 验证身份，只接受 `vendor` 角色。
4. 页面顶部“供货商登录入口”在新标签页打开本站 `/supplier/sign-in`，旁边的复制按钮可复制当前站点的完整登录地址。将该地址及本站供货商登录信息交给供货商，不要交付上游账号、密码或 Cookie。入口不会传递控制台登录凭据或自动冒充供货商；有查看权限的管理员即可使用。

每个供货商最多绑定 20 个实例。同一实例上的远端供货商身份不能绑定给多个本站供货商；同一供货商不能重复绑定同一实例。供货商门户始终在单一绑定范围内工作。

## 功能

- **账号池**：分页、搜索、状态、恢复窗口与排序，查看账号及账号池汇总。
- **用量统计**：查看 1、7、30 天请求、Token、消费、每日趋势和账号明细。金额缺失不补零。
- **代理管理**：批量文本导入、测试、启停和删除。服务端核验远端资源范围；只有自己拥有的代理允许启停。代理密码不会回传，也不会写入本站数据库或审计。
- **上传账号**：支持 OAuth 登录、自动 OAT、导入 RT 和批量导入 SK，仅使用 Anthropic/native。四种方式共用代理、分组、模板及限制配置。
- **密码**：供货商可以修改本站密码。修改后需重新登录。

### 策略模板与代理启停（v1.2.62）

- 选择或切换策略模板会填入 RPM、TPM、并发及会话上限，之后可手动调整。真实 `0` 保留；模板缺失或无效的参数留空，生成授权链接前需补全。
- 刷新上传选项不会覆盖已填写的参数；取消模板选择保留当前参数。授权链接冻结模板 ID 和最终限制值，交换时无法再次修改。
- 代理启停开关以服务端返回的能力为准。自有代理可启停；已分配代理与归属未确认的代理显示不同限制原因。缺少归属标记时仅按明确的归属用户 ID 和已验证的供货商身份核对，明确的非自有标记不会被覆盖。
- 修改代理状态前重新验证归属，成功后刷新代理列表与上传选项；失败保留原状态。手机端卡片直接显示启停、测试和删除操作。

### 门户布局与上传体验（v1.2.63）

- 桌面使用左侧实例选择和导航、右侧内容；小于 1024px 时改为抽屉导航。账号、用量、代理和安全设置按权限展示，宽表格在自身区域内横向滚动。
- “上传账号”位于账号页，弹窗包含配置、授权和导入结果。只有上传权限的供货商可以使用入口，但不会请求无权查看的账号数据。
- 弹窗固定当前实例，正文独立滚动、底部操作固定。存在草稿或授权流程时关闭需要确认；请求期间禁止关闭或重复提交。导入成功刷新账号与汇总，保留搜索和分页，可继续上传。
- 默认选择指定代理及首个可绑定代理；没有可绑定代理时保持为空，不能静默退回直连。
- 策略与 CC 模板记住当前浏览器中每个本站供货商、实例绑定最后成功上传的模板 ID。首次使用或模板被删除时选择第一项；没有 CC 模板时留空，没有策略模板时需手动填写四项限制。
- 默认模板使用当前上游限制值，允许手动修改，刷新不覆盖。浏览器只记忆模板 ID，不记忆限制值、密码、授权链接或回调内容。
- 授权步骤展示完整只读链接，支持复制和打开。复制失败时可以选中文本手动复制；无效或过期链接不能复制、打开或提交交换。
- 代理归属统一显示“自有”“已分配”“归属未确认”“归属信息冲突”。归属标记与明确的用户 ID 矛盾时禁止启停；列表与修改前的鉴权使用同一判断。
- 此版本没有核实特定线上代理的实际归属，不以“曾通过本站导入”推断拥有权，不使用管理员身份替代供货商操作。

验证包括 Go 全量测试、`go vet`、前端测试、类型检查、Lint、格式检查及生产构建；Edge 本地模拟接口验证桌面、手机、暗色模式、上传独立权限、模板选择与记忆、草稿关闭、请求防重、复制失败、链接过期和代理状态权限。没有对生产实例执行账号上传或代理修改。

读取请求由服务端转发，使用 30 秒缓存；手动刷新绕过缓存。临时故障时可以展示不超过 15 分钟的最后成功结果，并标注旧数据与原采集时间。认证、身份或权限失败不会使用旧缓存掩盖问题。该缓存独立于账号管理的 15 分钟快照采集。

### 多方式账号添加（v1.2.64）

- 账号页“上传账号”弹窗的“添加方式”默认是 OAuth 登录。自动 OAT 使用 `oauth_flow=setup_token` 生成链接，仍需提交回调，不是直接粘贴 OAT。两种授权方式继续冻结公共配置与流程类型，10 分钟过期且一次性消费。
- RT 导入需要账号名称及 Refresh Token，Access Token 可选；直接提交，不生成链接，也不覆盖已有账号。
- SK 导入需要名称前缀及 Session Key。按换行、中英文逗号分隔，去除空白并按大小写敏感去重，每批最多 20 个；超限整体拒绝。同步等待结果，不创建后台任务。
- 指定代理由服务端映射为 `existing + existing_ids`，自动代理映射为 `auto`，直连映射为 `direct`。提交前再次核验当前供货商权限、绑定、分组、模板和代理范围。
- SK 结果只展示序号、成功/重复/失败/未确认状态和安全中文原因。缺项、重复序号、错误序号及矛盾响应不得算作成功。RT 使用单项结果；未确认时应先刷新账号核对，不整批自动重试。
- 写请求最多 60 秒。仅明确的认证拒绝沿用原认证恢复机制；网络错误、超时、429、5xx 不自动重放导入。
- 切换方式保留公共配置，清空 RT、AT、SK、回调及旧流程；提交后清空敏感输入。请求期间禁用关闭、切换和重复提交。只有成功导入才记忆模板 ID 并刷新账号与汇总，保留分页和筛选。
- 新接口为 `POST /supplier-api/v1/account-upload/import-rt` 和 `/import-sk`。不修改数据库结构，密钥只在处理请求所需的内存中存在，不放入数据库、React Query mutation 缓存、浏览器持久化存储、审计或错误响应。

本版验证包括 Go 全量测试、`go vet`、前端 68 项测试、类型检查、Lint、格式检查、Knip 和生产构建。Edge 使用本地模拟接口验证桌面、手机及暗色模式的四种方式、参数保留与敏感输入清理、20 个上限、部分结果、超时不重放、模板记忆、过滤分页保留及原 OAuth 上传流程。未使用真实凭据，未执行线上账号导入。

### 管理端与门户界面（v1.2.66）

- 管理端、独立登录页及门户统一使用紧凑表单和表格；桌面保留 224px 左侧导航，小于 1024px 使用抽屉导航。手机端账号、用量、绑定和审计使用摘要与详情，长邮箱、IP 和账号标识可以完整查看。
- 管理端在同一详情弹窗中查看绑定、审计和编辑绑定，编辑期间离开需要确认丢弃；请求期间不能重复提交或关闭。表单提供具体字段错误，草稿仅在当前页面内存保留。
- 账号筛选支持重置，筛选命中数量与当前实例汇总分别标注。请求失败时可保留已加载的数据并显示错误提示，但认证失效、权限拒绝或资源移除不会继续展示缓存内容。采集时间仍使用接口返回值。
- 上传配置按账号、出站连接、模板与分组、容量限制排列。v1.2.67 起添加方式改为下拉选择，默认 OAuth 登录，保留自动 OAT、RT 和 SK。代理默认值、模板记忆、切换时敏感输入清理及一次性流程规则不变，请求期间禁止切换。
- 代理归属、健康状态和启用状态分别展示；金额支持鼠标悬浮、键盘聚焦或触屏点击查看完整精度。不增加采集请求，不修改 API、数据库或供货商权限。

### 门户柔和化视觉（v1.2.68）

- 独立登录页及门户使用浅灰页面底色、白色内容区和浅蓝选中态，汇总与筛选通过连续浅色背景带区分，不增加嵌套卡片。
- 门户控件与手机数据卡片采用 8px 圆角，桌面弹窗采用 12px；手机全屏上传弹窗保持无外圆角。上传标题、底部操作与表单分组采用淡色背景，暗色模式使用对应中性深灰层级。
- 样式通过 `supplier-experience` 单独隔离，并显式应用到门户弹窗、抽屉、金额提示及主题菜单；控制台供货商管理界面保持原样。接口、权限、缓存周期、金额及上传逻辑不变。

### 上传平铺选择（v1.2.69）

- 仅供货商上传弹窗的添加方式、出站方式、指定代理、策略模板和 CC 模板改为平铺单选方框；分组仍可多选。控制台管理页及门户其他下拉框不变。
- 添加方式在桌面显示四列、手机两列。代理与模板各占独立区域，桌面两列、手机单列，列表最大高度分别为 240px 与 200px，超出后内部滚动；长名称与地址完整换行。
- 实际代理或模板超过六个时显示本地搜索，代理可按名称、地址及端口搜索。搜索不会发起请求或清除选择，区域顶部持续显示当前选中项；无匹配时可清空搜索。
- 保留代理“未选择”、模板“不指定”、首个代理默认值、模板记忆及容量联动。没有可绑定代理时仍不能以指定代理模式提交。支持整块点击、方向键选择及错误字段定位；提交期间禁用选择和搜索。
- 搜索仅保留在当前弹窗内存，关闭后清空；四种上传流程、敏感输入清理、权限及服务端冻结参数不变。

本版使用 Edge 本地模拟接口检查 320、390、768、1440px 明暗主题、长选项、搜索、滚动、键盘及无代理校验，并回归四种上传流程。没有使用真实密钥或执行线上导入。

## 安全与运维

### 默认权限与数据可见性（v1.2.70）

- 控制台“供货商”顶部的“默认权限”配置全局功能与字段。供货商编辑、绑定编辑支持逐项“继承、允许、禁止”，展示最终结果与来源，并可全部恢复继承。优先级为实例绑定、供货商、全局默认；显式允许可以覆盖上级禁止，但不能绕过供货商或绑定停用。
- 四项功能为查看账号、查看用量、管理代理、上传账号。字段可按账号信息、自有账号汇总、全池指标和用量指标分别控制，合计 21 项配置。账号 ID、名称和用量日期保留为基本标识；不修改代理归属、上传配置与远端供货商权限。
- 费用、请求与 Token 的用量开关同时控制汇总、每日图表和账号明细。隐藏字段由服务端从响应中移除，允许但上游没有提供的字段为 `null`，真实零值保留；缓存和失败回退同样执行校验及裁剪。
- 隐藏邮箱时不能使用综合搜索；隐藏状态时不能使用状态与恢复窗口筛选。隐藏字段不能排序，缺省排序回退到名称。隐藏总账号数时不返回精确总数，分页只显示当前页及上一页、下一页；可见账号仍可被逐页枚举，不承诺阻止自行推算数量。
- 新供货商及新绑定默认继承。升级会幂等保留已有供货商的四项功能权限及全部现有字段可见性，已有绑定继承供货商；因此修改全局默认不会覆盖旧供货商的显式配置，可手动“全部恢复继承”后采用默认值。
- 权限变化会撤销受影响供货商的会话和未完成 OAuth 流程，旧请求不能继续返回数据。仅修改绑定权限不重新登录上游。配置差异进入安全审计，不包含凭据。
- 新增 `GET/PUT /api/suppliers/default-policy`，分别需要 `supplier_management:view/manage`。供货商及绑定接口增加 `policy_overrides` 和 `effective_policy`；保存可以携带 `policy_revision` 防止覆盖过期编辑。覆盖项缺省或 `null` 表示继承，未知键拒绝保存；全局配置需要完整的布尔项。

验证：Go 全量测试、迁移与权限测试、`go vet`、前端 73 项测试、类型检查、Lint、格式检查、Knip、生产构建，以及 Edge 本地模拟数据的桌面/手机、明暗主题、三级配置、隐藏字段和四种添加流程。未使用生产凭据，未连接或部署服务器。

### 上传账号固定前后缀（v1.2.72）

- 在“供货商 → 编辑 → 账号命名规则”设置固定前缀和后缀；在“绑定管理 → 编辑”选择继承供货商规则或自定义。自定义两项均为空时，该绑定不添加前后缀，不影响其他实例。
- 服务端将门户提交的名称作为主体，统一生成“前缀 + 名称主体 + 后缀”。不补分隔符，不移除重复前后缀，不截断名称。前后缀与主体去除首尾空白且拒绝控制字符；前后缀合计最多 63 个 Unicode 字符，完整名称最多 64 个字符。
- OAuth 登录、自动 OAT 与 RT 导入使用完整名称。OAuth 生成链接时冻结名称，交换时仅接收流程 ID 和回调；规则变更使待处理流程失效，旧版本提交提示刷新配置。已经接受并发送至上游的操作不追溯修改。
- SK 仅在有效后缀为空时可用：固定前缀与填写内容组成上游 `name_prefix`，最终账号名仍由上游生成。有后缀时前端禁用 SK，后端也拒绝直接提交；不增加导入后改名操作。
- 管理端只读详情展示生效规则和来源；门户展示固定前后缀及完整名称预览。规则修改需要原有管理权限，审计记录规则变更，不记录令牌、回调或上传请求正文。
- 供货商新增 `naming_rule`，绑定新增可空 `naming_override`，有效配置为 `effective_naming`（前后缀、来源、版本）。提交可携带 `naming_revision` 校验版本。旧客户端不传版本时仍由服务端应用当前规则；不传命名配置不会清空已有规则，绑定显式 `null` 恢复继承。
- 旧数据升级后前后缀为空、绑定继承；只影响通过本站门户新上传的账号，不重命名已有账号、不限制远端平台直接操作，也不增加上游采集请求。沿用现有管理端保存后的会话撤销行为。

验证使用合成数据：迁移及重复迁移、配置继承和隔离、Unicode 长度边界、旧客户端、三种完整名称上传、SK 限制、缓存规则更新、OAuth 冻结与并发变更；Edge 覆盖 320、390、768、1440px 明暗主题。没有使用生产凭据或执行线上上传。

### 会话与敏感数据

- 生产门户必须通过 HTTPS 使用。独立 Cookie 为 `supplier_session`，路径 `/supplier-api/v1`，具有 `Secure`、`HttpOnly`、`SameSite=Strict` 属性，会话固定有效 12 小时。
- 门户与控制台身份、查询客户端和会话互相隔离。修改请求验证 CSRF；跨来源登录被拒绝。
- 登录按本站账号和解析后的真实 IP 限制，15 分钟最多 5 次失败。启用 Redis 时使用共享计数；未启用时按当前节点计数。仍应正确配置 `TRUSTED_PROXIES`。
- 上游密码使用现有 `MANAGED_INSTANCE_SECRET_KEY` 加密，绑定和 OAuth 流程使用各自的关联数据。升级时必须保留原主密钥；不应为安装此功能更换已有主密钥。
- 上游 Access Token 与 Cookie 仅存在服务端内存，过期优先刷新，身份校验失败不会退回管理员身份。
- 停用、软删除、修改权限、重置密码或撤销会话都会使现有门户会话失效。修改或删除绑定使其待处理 OAuth 流程失效。
- OAuth 流程绑定供货商、会话、实例及冻结参数，10 分钟过期，交换前原子消费。即使交换时网络失败，也不能重复使用该流程，应先确认上游结果，再按需重新生成。
- 本站不提供修改或删除已有上游账号的操作，也不提供管理员冒充登录。
- 审计只记录动作、供货商、绑定、管理员、IP、状态、耗时和安全错误码，不保存请求正文、密码、代理导入文本、授权码或上游原始响应。过期会话、OAuth 流程和 90 天前审计按小时访问触发分批清理。

对话、截图或抓包中暴露的任何密码、Cookie、访问令牌、代理凭据及授权码，应在对应系统中撤销或轮换。功能实现和自动测试不依赖这些凭据。

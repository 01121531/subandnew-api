# Claude Gateway 供货商管理

## 开通

1. 超级管理员进入“供货商管理”，创建本站供货商账号和独立密码。普通管理员需要另行授予 `supplier_management` 的查看、管理、审计权限。
2. 默认只开放账号池和用量统计；代理管理与 OAuth 上传需要主动启用。
3. 为供货商绑定已创建的 Claude Gateway 实例，输入该实例上的供货商登录账号和密码。保存时通过上游登录及 `/api/auth/me` 验证身份，只接受 `vendor` 角色。
4. 将本站 `/supplier/sign-in` 地址及本站登录信息交给供货商。不要交付上游账号、密码或 Cookie。

每个供货商最多绑定 20 个实例。同一实例上的远端供货商身份不能绑定给多个本站供货商；同一供货商不能重复绑定同一实例。供货商门户始终在单一绑定范围内工作。

## 功能

- **账号池**：分页、搜索、状态、恢复窗口与排序，查看账号及账号池汇总。
- **用量统计**：查看 1、7、30 天请求、Token、消费、每日趋势和账号明细。金额缺失不补零。
- **代理管理**：批量文本导入、测试、启停和删除。服务端核验远端资源范围；只有自己拥有的代理允许启停。代理密码不会回传，也不会写入本站数据库或审计。
- **上传账号**：仅支持 Anthropic 登录流程和 native 后端。选择代理、分组和模板后生成授权地址，再提交完整回调地址或 `code#state`。参数在生成时冻结；修改配置需重新生成。
- **密码**：供货商可以修改本站密码。修改后需重新登录。

### 策略模板与代理启停（v1.2.62）

- 选择或切换策略模板会填入 RPM、TPM、并发及会话上限，之后可手动调整。真实 `0` 保留；模板缺失或无效的参数留空，生成授权链接前需补全。
- 刷新上传选项不会覆盖已填写的参数；取消模板选择保留当前参数。授权链接冻结模板 ID 和最终限制值，交换时无法再次修改。
- 代理启停开关以服务端返回的能力为准。自有代理可启停；共享代理与归属未确认的代理显示不同限制原因。缺少归属标记时仅按明确的归属用户 ID 和已验证的供货商身份核对，明确的非自有标记不会被覆盖。
- 修改代理状态前重新验证归属，成功后刷新代理列表与上传选项；失败保留原状态。手机端卡片直接显示启停、测试和删除操作。

读取请求由服务端转发，使用 30 秒缓存；手动刷新绕过缓存。临时故障时可以展示不超过 15 分钟的最后成功结果，并标注旧数据与原采集时间。认证、身份或权限失败不会使用旧缓存掩盖问题。该缓存独立于账号管理的 15 分钟快照采集。

## 安全与运维

- 生产门户必须通过 HTTPS 使用。独立 Cookie 为 `supplier_session`，路径 `/supplier-api/v1`，具有 `Secure`、`HttpOnly`、`SameSite=Strict` 属性，会话固定有效 12 小时。
- 门户与控制台身份、查询客户端和会话互相隔离。修改请求验证 CSRF；跨来源登录被拒绝。
- 登录按本站账号和解析后的真实 IP 限制，15 分钟最多 5 次失败。启用 Redis 时使用共享计数；未启用时按当前节点计数。仍应正确配置 `TRUSTED_PROXIES`。
- 上游密码使用现有 `MANAGED_INSTANCE_SECRET_KEY` 加密，绑定和 OAuth 流程使用各自的关联数据。升级时必须保留原主密钥；不应为安装此功能更换已有主密钥。
- 上游 Access Token 与 Cookie 仅存在服务端内存，过期优先刷新，身份校验失败不会退回管理员身份。
- 停用、软删除、修改权限、重置密码或撤销会话都会使现有门户会话失效。修改或删除绑定使其待处理 OAuth 流程失效。
- OAuth 流程绑定供货商、会话、实例及冻结参数，10 分钟过期，交换前原子消费。即使交换时网络失败，也不能重复使用该流程，应先确认上游结果，再按需重新生成。
- 本站不提供修改或删除已有上游账号的操作，也不提供管理员冒充登录。
- 审计只记录动作、供货商、绑定、管理员、IP、状态、耗时和安全错误码，不保存请求正文、密码、代理导入文本、授权码或上游原始响应。过期会话、OAuth 流程和 90 天前审计按小时访问触发分批清理。

对话、截图或抓包中暴露的任何密码、Cookie、访问令牌、代理凭据及授权码，应在对应系统中撤销或轮换。功能实现和自动测试不依赖这些凭据。

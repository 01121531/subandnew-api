# 邮箱悬浮助手

Windows 10/11 x64 免安装客户端。解压整个 ZIP 后运行 `MailboxAssistant.exe`，不要单独移动 EXE 或删除 `_internal`。

## 使用

1. 输入本站 HTTPS 地址、管理员创建的操作员用户名和密码。证书必须有效；客户端不支持 HTTP、忽略证书或跳转到其他站点。
2. 选择退款邮箱或开号邮箱，只展示当前分配的待处理及已退回任务。上下条可跨页，提交记录是只读的。
3. 点击邮箱、密码、验证码、卡号、有效期或临时 CVV 的数值区域复制。卡号不带分隔符，密码原文和前导零保持不变。
4. 截图后在应用内按 Ctrl+V，或点击粘贴截图。预览并遮挡完整卡号及 CVV 后提交，成功后自动进入下一条。每次最多 5 张，每张最多 10MB。
5. 使用顶部置顶、折叠和系统托盘。普通失焦不会清空资料；折叠、最小化、锁屏、换任务或退出会清除敏感字段。展开后重新检查权限并获取资料。

提交失败会保留已成功上传的附件，结果不确定时只查询提交记录，不自动重放。离开有截图草稿的任务需要确认，退出后不保存草稿。

### 没有任务或读取失败

“没有待处理或已退回任务”不是程序卡死：当前类型下没有可供此操作员处理的任务。请在后台确认分配的操作员、退款/开号类型及任务状态；待审核、已通过和异常待处理不会进入可处理队列。管理员分配或恢复任务后，点击“刷新任务”，也可以切换另一类型或查看提交记录。

空队列不显示截图、反馈及提交操作。网络失败、数据格式异常和任务状态不匹配会分别提示，不会伪装成没有任务；刷新后仍失败时请确认站点及服务端版本，联系管理员核对。没有截图时点击提交会提示先粘贴截图。

v1.2.82 起采用与网页一致的普通分配列表接口，不再依赖旧服务端不认识的 `status=actionable` 参数。客户端仅保留待处理及已退回任务，自动跳过只含待审核、已通过或异常待处理记录的分页；这些分页只读取列表，不提前读取其他邮箱凭据。下一条/上一条保持邮箱 ID 顺序。历史记录较多时可能需要读取多页，界面保持加载状态。

## 异常反馈

服务端需升级至 v1.2.80。待处理及已退回任务可点击“反馈问题”，选择邮箱无法登录、验证码异常、信用卡不可用（仅开号）或其他，填写 1～2,000 字说明。允许不附图，或粘贴最多五张截图；原正常截图草稿须确认丢弃，不会自动转为反馈附件。

不要在说明中填写密码、2FA 密钥、完整卡号或 CVV；截图需先遮挡这些内容。提交成功后当前任务暂停、停止凭据读取并自动下一条。结果不确定时仅查询反馈记录，不重复提交。

“记录”中的异常反馈记录可查看问题、处理状态及管理员回复。管理员修正后恢复给原操作员的任务会重新出现在待处理队列；回收或改派不会转交旧反馈和截图。

## 安全边界

- 会话最长 12 小时。可选择使用当前 Windows 用户的 DPAPI 加密记住会话，不保存登录密码。设置位于 `%LOCALAPPDATA%/MailboxAssistant`，仅包含站点、用户名和加密会话；启动时仍需服务端验证。
- 仅当前任务读取凭据，每 30 秒检查分配，复制及提交前再检查。断网不会继续复制旧资料。
- 普通复制内容 30 秒、CVV 15 秒后尝试清除，且只清除仍属于本次复制的内容。无法撤回其他程序已读取的内容、剪贴板历史、云同步或截图；处理敏感资料前关闭系统剪贴板历史与跨设备同步。
- CVV 仅适用于实际授权前的一次性交付，不得用于授权后保存或重复交易。服务端最长保留 10 分钟，领取一次即删除；客户端最多展示 60 秒且不超过交付期限，复制即清除。领取响应丢失不会重试，需要管理员重新提供。
- 不保证 Python/Qt 或操作系统所有内存副本被物理擦除。不得开启请求正文日志、内存转储、第三方剪贴板记录或截图录制。
- 客户端不会登录 Google、读取邮件、自动截图、监听全局剪贴板或执行支付。

## 服务端配置

服务端升级至 v1.2.79 或以后版本。临时 CVV 默认关闭，仅确认单节点运行时设置 `MAILBOX_TEMP_CVV_MODE=single_node`。从节点不启用，多节点禁止设置此开关；进程重启会丢失所有临时值。容量上限 10,000 条，满时整批拒绝导入，不写数据库或 Redis。

退款维持 3 列；开号支持原 5 列以及可选第 6 列 CVV。CVV 必须是三位或四位数字字符串，Excel 卡号和 CVV 使用文本单元格。预览不回显 CVV。确认导入后应立即安全销毁含 CVV 的源文件及其副本，勿纳入备份。管理员可从开号邮箱行的临时 CVV 操作入口补发，需导入管理及凭据访问权限。

回收、改派、停用、提交审核会使未领取的 CVV 失效。审核通过后所有凭据访问停止。已复制的信息无法远程撤销，必要时轮换实际邮箱凭据。

这不是支付数据合规认证。部署者仍须遵守 [PCI SSC 关于 CVV 的要求](https://www.pcisecuritystandards.org/faqs/1280/)，并评估主机内存、交换文件、备份、截图和源文件的风险。

## 构建与许可

```powershell
py -3.12 -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m pytest
.venv/Scripts/python -m ruff check .
.venv/Scripts/python -m mypy
.venv/Scripts/python build.py
```

使用 Python 3.12.10 x64 构建，PySide6 6.11.2、PyInstaller 6.22.3。测试 TLS 需要 OpenSSL 命令行（Git for Windows 中已包含）。输出位于 `dist`，含 SHA-256。程序没有自动更新器，需要下载新版本并完整解压。

本项目按根目录 AGPL-3.0 许可发布。`LICENSES` 包含运行时与依赖许可，`SOURCE-NOTICE.md` 和同版本 sources ZIP 提供源码及构建说明。Qt/PySide 动态库可以替换，不禁止为调试其修改而进行逆向工程。应用未作代码签名，首次运行可能出现 Windows SmartScreen 提示；应先核对发布页 SHA-256，不要关闭系统防护。
